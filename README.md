## a. ¿Qué es un pull request en GitHub?

Un pull request es una solicitud para fusionar cambios de una rama a otra en un repositorio de GitHub. Es un mecanismo de colaboración que permite a los desarrolladores proponer modificaciones al código de forma controlada. El PR facilita la revisión de código, discusión de cambios y aprobación antes de integrar los cambios a la rama principal (generalmente `main` o `master` o  `develop`).

## b. ¿Cómo se crea un pull request en GitHub?

1. **Crear una rama**: Crea una rama local con tus cambios
2. **Realizar cambios**: Edita los archivos necesarios
3. **Hacer commit**: Guarda los cambios
4. **Hacer push**: Sube la rama al repositorio remoto
5. **Abrir el PR**: En GitHub, aparecerá un botón "Compare & pull request" o ve a "Pull requests" → "New pull request"
6. **Completar detalles**: Agrega título, descripción y selecciona las ramas (donde está tu cambio → donde va a fusionarse)
7. **Crear el PR**: Haz clic en "Create pull request"

## c. ¿Cómo se aprueba un pull request en GitHub?

1. **Revisar el PR**: Ve a la pestaña "Pull requests" y selecciona el PR
2. **Revisar cambios**: Examina los archivos modificados en la pestaña "Files changed"
3. **Agregar comentarios**: Comenta en líneas específicas si hay observaciones
4. **Aprobar**: 
   - Haz clic en "Review changes"
   - Selecciona "Approve"
   - Agregue un comentario opcional
   - Haz clic en "Submit review"
5. **Fusionar**: Con las aprobaciones necesarias, haz clic en "Merge pull request" y confirma
